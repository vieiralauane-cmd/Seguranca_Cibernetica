# Segurança Cibernética

Projeto acadêmico desenvolvido para a atividade
avaliativa de Banco de Dados I e II.

## Objetivo
Desenvolver um banco de dados relacional para
registrar e gerenciar incidentes cibernéticos.

## Tecnologias utilizadas
- SQLite
- SQL
- GitHub

## Curso
Técnico em Desenvolvimento de Sistemas.
